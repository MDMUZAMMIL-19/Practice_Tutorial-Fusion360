# Autodesk Fusion 360 Design & Prototyping Portfolio

This repository archives CAD models, electronic integrations (ECAD/MCAD), sheet metal fabrications, and mechanical assemblies developed in **Autodesk Fusion 360**. 

The projects span parametric 3D modelling, mechanical part assemblies, sheet metal workflows, embedded robotics design, and integrated electronic schematic/PCB layouts.

---

### Project Categories & Modules

| Category / Directory | Focus Area | Included Assets & Models |
| :--- | :--- | :--- |
| **Fusion Electronics** | ECAD/MCAD Co-Design | Embedded Arduino layouts, EAGLE interoperability workflows, Game Controller PCB, and electronic schematic captures |
| **Gas Sensor Robot** | Integrated System Design | Complete robotic assembly archive (`.f3z`), engineering technical drawings (`.pdf`), visual renders, and firmware source code |
| **Practice Sheet Metal tutorial** | Sheet Metal Fabrication | Parametric sheet metal bends, flat-pattern generation, and standardized STEP exports (`.step`) including steel bracket components |
| **Starting Fusion360** | Parametric CAD Foundations | Core modelling operations: Extrude/Revolve features, threaded fasteners (`nut+bolt assembly`), motor housings, glass bottle profiles, and sheet components |

---

### Key Workflows & Techniques

* **Parametric 3D Modelling:** Sketch constraints, multi-body modelling, revolve operations, and parametric feature trees.
* **Mechanical Assemblies:** Rigid and revolute joint configurations, component clearance analysis, and standard hardware integration.
* **Sheet Metal Design:** K-factor bend allowances, sheet rule definitions, flange generation, and unfolded flat patterns.
* **ECAD Integration:** 3D PCB package modelling, enclosure fitting, and mechanical constraint checks for electronic boards.
